# Sirohi Capital website

Static website for Sirohi Capital (Canada & India).

- `index.html`: home page
- `finance.html`: Finance page
- `images/`: photos and partner logos
- `media/`: Vernon drone video (MP4 + WebM) and poster image
- `sirohi-capital-logo*.svg|png`: logo files

## Deploy
Hosted on Cloudflare Pages, connected to this repository.
Build settings: Framework preset **None**, build command **empty**, build output directory **/**.
Every push to `main` redeploys the site.

## WhatsApp number
Change `WHATSAPP_NUMBER` near the bottom of `index.html` and `finance.html` (digits only, country code first).
